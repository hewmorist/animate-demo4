# Object to Be Destroyed

A working 3D metronome study after Man Ray. Swipe or drag to orbit. Set 30–240 BPM with the slider, or tap four times to average your tempo. Start enables the beat and swinging arm; Sound toggles the click.

Browser runtime only: WebAssembly, HTML/JavaScript, eye image and the third-party loader with its MIT notice. No Rust source or private development notes. Serve the branch root directly with GitHub Pages; no build required. The page shows runtime revision b9c35f9.
